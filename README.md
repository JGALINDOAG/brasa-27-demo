# Brasa 27 — Demo de restaurante

Sitio ficticio de menú digital creado como demostración por Innovamoments.

## Publicación con GitHub Pages

El sitio es HTML, CSS y JavaScript estático. Configura **Settings → Pages → Deploy from a branch → main / (root)**. La página principal es `index.html`.

El QR apunta a `https://jgalindoag.github.io/brasa-27-demo/#menu`. Si cambias el nombre del repositorio, regenera `assets/menu-qr.svg`. Los pedidos, precios, horarios y enlaces de entrega son demostrativos. Para un negocio real, configura sus propios datos y enlaces.
